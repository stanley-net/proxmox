# Proxmox VE Homelab

## Overview

This repository documents my Proxmox VE homelab project, developed to gain practical experience in virtualization, networking, and server administration.

## Project Goals

- Install and configure Proxmox VE
- Document the server installation and initial configuration
- Configure network connectivity and management access
- Learn virtualization and infrastructure administration
- Expand the environment as new skills are acquired

## Environment

- **Hypervisor:** Proxmox Virtual Environment (VE)
- **Project type:** Home lab
- **Documentation:** Markdown
- **Version control:** Git / GitHub

## Documentation

Technical documentation, configuration steps, and project updates will be added as the homelab develops.
